# النطاق 01: التنظيم والوصول وتهيئة المنشأة

**الحالة: مغلق مبدئيًا من حيث الحدود والقواعد بعد مراجعة الاتساق؛ الاعتماد النهائي مع وثائق النظام المتكاملة.**

## الهدف والحدود

تهيئة مساحة المنشأة بعد تجهيزها، وتنظيم مستخدميها ووصولهم وبدء العمل. استقبال الاشتراك والدفع والتجهيز والترخيص يتبع النطاق 08.

## أجزاء النظام ضمن النطاق

| الجزء | ما يشمله |
| --- | --- |
| أول دخول | قبول دعوة المالك والتحقق من هويته وربط وصوله بالمساحة المجهزة. |
| الإعداد وبيانات المنشأة | المعالج والتخطي والاستئناف والإتمام؛ البيانات والأنشطة واللغة والعملة والمنطقة الزمنية وإعداداتها الدائمة. |
| الهيكل التنظيمي | الفروع والمناطق والأقسام الاختيارية وعلاقاتها. |
| المستخدمون والوصول | الدعوات والأدوار ونطاقات الصلاحيات ونقل الملكية وتعطيل الوصول. |
| استحقاقات الباقة والاستخدام | تطبيق القدرات وحدود المقاعد والفروع؛ عرض الاستخدام وطلب تغيير الباقة وحالته. |
| اختيار قالب البداية | اختيار قالب بداية واحد لمسار المنشأة وإحالته إلى إعدادات التشغيل. |
| التدقيق | تسجيل تغييرات هذا النطاق وعرضها بحسب الصلاحية. |

## ارتباطات تتبع نطاقات أخرى

- **الاشتراك والتجهيز والترخيص، النطاق 08:** موقع الباقات وطلب الاشتراك والدفع وتجهيز المساحة ودعوة المالك؛ يستقبل هذا النطاق البيانات المحفوظة وقدرات الترخيص. لا توجد لوحة SaaS في الإصدار الأول.
- **التشغيل والاعتمادات:** تحرير مسار المنشأة ومراحله وشروطه واستثناءاته والمهام والإسناد؛ تستخدم الهيكل والصلاحيات المعرفين هنا.
- **المنتجات والجاهز والمخزون:** الكتالوج والنسخ والموردون والمخزون وطلبات الجاهز؛ ترسل حالة الالتزامات لاستكمال التخفيض.
- **الموقع ومساحة العميل:** الصفحات والمحتوى والمتجر وحساب العميل وتتبع الطلبات؛ ترتبط بالمنشأة وتلتزم بالباقة والوصول.
- **المالية التشغيلية:** دفعات عملاء الجهة والتحصيل والإيصالات والاسترداد؛ منفصلة عن اشتراك OpsOne.
- **الخدمات المشتركة:** إرسال الإشعارات والمساعدة داخل المنصة وحفظ سجل التدقيق؛ يحدد هذا النطاق أحداثه ورسائله ومساعدته.

## بداية العمل

- يستقبل المالك دعوة آمنة بعد ثبوت الدفع في الخلفية وتجهيز المساحة وتسليمها وفق النطاق08؛ اختيار الباقة أو رفع إثبات التحويل وحده لا يتيح الدخول.
- يقبل المالك الدعوة ويثبت ملكية وسيلة الدخول برمز على الجوال، أو على البريد الموثق المرتبط بالدعوة إن تعذر الجوال، ويعين كلمة مروره؛ بيانات الاشتراك أو تطابق البريد وحدهما لا يمنحان ملكية.
- بيانات الجهة محفوظة من طلب الاشتراك، ويبدأ المعالج بأول خطوة غير مكتملة مع إمكانية مراجعتها صراحةً.
- يستكمل التنظيم ومسار التشغيل ودعوة الفريق والمراجعة، أو يحفظ التقدم ويؤجله.

## سلوك معالج الإعداد

- الخطوات: بيانات المنشأة، تنظيم العمل، مسار التشغيل، دعوة الفريق، المراجعة والإتمام.
- تحفظ حالة اكتمال كل خطوة. يبدأ المعالج ويستأنف من أول خطوة غير مكتملة؛ بيانات الاشتراك مكتملة مسبقًا. التخطي يحفظ المدخلات دون اعتبار الخطوة مكتملة، والرجوع للمراجعة لا يمحو التقدم.
- توضح كل خطوة مكان إعداداتها الدائم: بيانات المنشأة، الهيكل التنظيمي، مسار التشغيل، أو الموظفون والدعوات.
- بعد «إتمام الإعداد» يغلق المعالج نهائيًا ويختفي مدخله؛ تبقى جميع الخيارات قابلة للتعديل من صفحاتها الدائمة.
- تأجيل المعالج لا يتجاوز الشروط اللازمة لإجراء بعينه، مثل إعداد صلاحية أو وسيلة دفع.
- موقع واحد يعمل دون مناطق أو أقسام. تفعيلها وإنشاء الفروع والأقسام ودعوة الموظفين متاح من المعالج ومن الصفحات الدائمة.

## الواجهة المشتركة

- النقر على الحساب يفتح اللغة، والمظهر حسب الجهاز أو فاتح أو داكن، وتسجيل الخروج. تحفظ التفضيلات دون فقد المدخلات.
- الجرس يفتح درجًا جانبيًا بإشعارات المستخدم المسموح بها فقط، مع فواصل خفيفة وحالة قراءة ووقت ورابط التفاصيل وتعيين الكل كمقروء؛ لا تمنح روابطه صلاحية إضافية.
- تظهر رسائل الحقول المطلوبة والصيغ والتكرار والحدود عند الحقل وباللغة المختارة، مع إبقاء القيم وتركيز أول حقل يحتاج تصحيحًا. أخطاء الإجراء العام تظهر قربه.
- تستخدم تسميات واضحة ومسافات أو صفوفًا وفواصل بصرية خفيفة؛ لا تستخدم النقطة الوسطية أو الشرطة الطويلة لفصل المعلومات.

## قواعد العمل

- الموقع الواحد يعمل مباشرة دون إعداد هيكل شكلي. المناطق تجمع الفروع اختياريًا، والقسم قد يخدم فرعًا أو عدة فروع.
- للموظف دور أو أكثر مع نطاق محدد لكل دور. تجمع الصلاحيات داخل نطاق الدور الذي منحها؛ لا يوسع نطاق دور محدود صلاحيات دور آخر.
- عضوية الفرع أو القسم لا تكفي لمنح صلاحية. الإجراء يتطلب: قدرة في الباقة، وصلاحية للمستخدم، ونطاق بيانات مناسب، وتحقق شروط العمل.
- أدوار البداية كما في مصفوفة الصلاحيات: المالك، المدير، مشرف القسم، المبيعات، المنفذ، المسؤول المالي، المخزون والتوريد، المحتوى. يجوز إنشاء أدوار مشتقة بإجراءات معروفة؛ الأسماء قابلة للتعديل عدا دور المالك، فصلاحياته ثابتة كاملة ضمن الباقة. صلاحيات الدور تعرض بلغة العمل في مجموعات، ونطاقه يحدد لكل عضو عند منحه الدور.
- نطاقات البيانات: المسند إليّ، قسم، فروع محددة، منطقة، أو كامل المنشأة. يمكن خدمة عدة فروع دون إتاحة جميع بياناتها.
- المالك يدير المنشأة ضمن باقتها؛ لا يمنح نفسه قدرات غير مشتركة أو وصولًا لمنشأة أخرى. تفصل ملكية الحساب عن الأدوار التشغيلية.
- الدعوة تحدد الدور والنطاق وتحجز مقعدًا؛ صلاحيتها سبعة أيام، وتجديدها يلغي رابطها السابق. المنتهية أو الملغاة تحرر المقعد. لا يجوز قبولها مرتين.
- الحساب هوية واحدة بجوال واحد وبريد واحد فريدين داخل مساحة المنشأة، مع إثبات الملكية. قواعد الجهات وملفاتها مستقلة مع كود مركزي واحد، دون حساب عملاء مركزي مشترك في الإصدار الأول؛ لا تكرار للحساب داخل الجهة ولا وصول من حساب جهة إلى أخرى.
- الموظف النشط يحسب مرة واحدة داخل المنشأة ولو تعددت أدواره. الدعوة المعلقة تحجز مقعدًا واحدًا للشخص؛ قبولها يحول الحجز إلى عضوية دون عد مزدوج. حساب العميل لا يحسب مقعدًا.
- قبول الدعوة يتطلب إثبات ملكية وسيلة الدعوة، وإعادة التحقق من صلاحية الدعوة والدور والنطاق واستحقاق الباقة وقت القبول. لا يكتسب العميل أو موظف منشأة أخرى وصولًا بمجرد تطابق البريد.
- الدخول واستعادة الحساب والخروج وإبطال الجلسات ترتبط بهوية موثقة؛ إعادة التعيين أو تغيير وسيلة الدخول لا ينقل ملكية المنشأة تلقائيًا.
- تعطيل الموظف يمنع دخوله ويلغي جلساته داخل مساحة الجهة ويحفظ تاريخه؛ لا يؤثر في حساب مستقل لدى جهة أخرى.
- عند طلب التعطيل مع أعمال مفتوحة، يوقف وصول الموظف فورًا، وتُنقل الأعمال إلى مؤهل أو صندوق متابعة مسؤول معلوم. لا تترك أعمال بلا جهة متابعة.
- تعطيل فرع أو قسم يتطلب معالجة أعماله وقواعد الإسناد المرتبطة به؛ يمنع الإسناد الجديد إليه وتبقى السجلات. لا تحذف الجهات أو الأدوار المستخدمة تاريخيًا.
- كل منع يعرض حله في موضعه وبحسب الصلاحية: إعادة إرسال الرمز أو إرساله للبريد الموثق المرتبط بالدعوة، وتجديد الدعوة المنتهية، وعند امتلاء المقاعد إلغاء دعوة أو تعطيل عضو مع معالجة أعماله أو طلب زيادة المقاعد ضمن الباقات المتاحة. القسم بلا مشرف تصل أعماله لصندوق متابعة المدير المخول ضمن نطاقه، وإلا المالك، لإسنادها دون تركها بلا متابعة. لا يغير المستخدم وسيلة الدعوة لإثبات هويته بمجرد التعذر، وتبقى حدود محاولات الرمز وانتهائه سارية.
- نقل الملكية يتطلب إعادة تحقق المالك الحالي وقبول المستخدم الجديد النشط؛ لا تترك المنشأة دون مالك. لا يجوز منح صلاحيات تتجاوز صلاحية المانح أو نطاقه. تعاد مراجعة الصلاحية والنطاق عند التنفيذ، وتطبق تغييراتها على الجلسات القائمة.
- صلاحية مهمة عابرة للفروع تمنح فقط بياناتها والوثائق اللازمة لها؛ لا تتيح بقية الطلب أو كامل ملف العميل. المرجع المشترك كاسم العميل أو المنتج لا يوسع نطاق الوصول.
- العملة تثبت بعد أول حركة مالية؛ تغييرها يحتاج معالجة مستقلة. تغيير اللغة أو المنطقة الزمنية لا يعيد كتابة السجلات التاريخية.
- تجهز المساحة بالمسار الافتراضي منشورًا (خمس مراحل، والقياس والتصميم فيه عند الحاجة)؛ اختيار قالب بداية آخر صالح ومهيأ بصلاحية P-21 يستبدل المنشور فور التأكيد للطلبات الجديدة فقط، والتخطي يبقي الافتراضي فلا يتوقف فتح الطلبات. لا يتطلب القالب أقسامًا أو موظفين غير موجودين؛ يبدأ الإسناد بمسؤول الطلب أو صندوق متابعة معلوم. تستكمل الأهلية أو المتطلبات الخاصة بالفعل عند تنفيذه دون اختلاق اعتماد أو قبض أو تجاوز ضوابط السلامة.  المراحل والإسناد وحفظ إعداد الطلب الجاري يملكها نطاق التشغيل. لا يغير تعديل المسار الطلبات الجارية تلقائيًا.
- تشغيل اشتراكات OpsOne منفصل عن أدوار المنشأة. أي وصول دعم استثنائي إلى بياناتها يكون محددًا ومصرحًا ومسجلًا.

| الـ ORG-01 | تهيئة المنشأة وإعداداتها | البدء بموقع واحد دون منطقة أو قسم، مع التحقق من الحقول المطلوبة. |
| الـ ORG-02 | الفروع والمناطق والأقسام | إضافة الهيكل وربطه وتعطيله دون فقد التاريخ أو الأعمال. |
| الـ ORG-03 | اختيار قالب البداية | حفظ قالب البداية لمسار المنشأة الواحد وإحالته إلى إعدادات التشغيل؛ تحريره وحماية الطلبات الجارية يتبعان نطاق التشغيل. |
| الـ ORG-04 | الموظفون والدعوات | قبول صالح لمرة واحدة، ومنع التكرار وتجاوز المقاعد حتى مع الطلبات المتزامنة. |
| الـ ORG-05 | الأدوار والصلاحيات | منح الإجراء داخل نطاقه فقط، ومنع تصعيد الصلاحيات ونقل الملكية غير المخول. |
| الـ ORG-06 | تعطيل المستخدم | وقف الوصول والجلسات، وحفظ التاريخ، وإظهار الأعمال المنقولة أو المحتاجة للتوزيع. |
| الـ ORG-07 | إتاحة الهيكل للتشغيل | يوفر للتشغيل الأقسام والأعضاء النشطين وأدوارهم ونطاقاتهم لتحديد المؤهلين. |
| الـ ORG-08 | أثر التعطيل على التشغيل | يمنع إسناد جديد إلى المعطل، وتحال أعماله القائمة لمتابعة مسؤول معلوم؛ تنفذ إعادة الإسناد في نطاق التشغيل. |
| الـ ORG-09 | الوصول والعزل | منع بيانات منشأة أخرى أو فرع خارج النطاق عبر API والملفات والبحث والتصدير، وليس بإخفاء الواجهة فقط. |
| الـ ORG-10 | فصل الوصول | تمنع هوية العميل من الوصول إلى إدارة المنشأة؛ تفاصيل حسابه وطلباته تتبع نطاق مساحة العميل. |
| الـ ORG-11 | الباقة والاستخدام | إظهار الحدود وسبب المنع، ومنع زيادة المورد المتجاوز دون حذف أعمال التخفيض. |
| الـ ORG-12 | سجل التغييرات | المستخدم والوقت والمنشأة والإجراء والقيم السابقة واللاحقة والسبب؛ العرض بحسب الصلاحية ودون تعديل السجل. |
| الـ ORG-13 | العربية والإنجليزية والمساعدة | ترجمة عناصر الواجهة والتحقق والحالات، واتجاه صحيح، ومساعدة مرتبطة بالشاشة. |
| الـ ORG-14 | إثبات الهوية والجلسات | لا تنشئ بيانات الاشتراك وحدها جلسة؛ يتطلب قبول الدعوة وإعادة تعيين الحساب إثبات الملكية، وتنعكس إزالة الصلاحية على الجلسات القائمة. |
| الـ ORG-15 | جاهزية أول دخول | لا تتيح دعوة المالك أو إعادة المحاولة دخول مساحة غير جاهزة؛ متابعة التجهيز والدفع تتبع SUB-01 وSUB-02 في النطاق 08. |

## قبول أول دخول والتهيئة

- الـ **ONB-01:** تستخدم بيانات الجهة ومسؤول الحساب من الاشتراك دون إعادة إدخال؛ يبدأ المعالج بأول خطوة غير مكتملة.
- الـ **ONB-02:** لا تتيح بيانات طلب اشتراك أو إيصال غير مؤكد جلسة دخول أو ملكية.
- الـ **ONB-03:** المساحة غير الجاهزة تبقى في متابعة طلب الاشتراك بالنطاق 08؛ لا يدخل المالك إلى إعداد ناقص.
- الـ **ONB-04:** تأجيل المسارات يعيد الاستكمال إليها حتى بعد إعادة فتح الصفحة، دون إعادة البيانات المكتملة.
- الـ **ONB-05:** إتمام المعالج يغلق مدخله وتبقى صفحات الإعدادات الدائمة.
- الـ **ONB-06:** يستخدم نظام التصميم وشعار OpsOne الصحيح في الإدارة، ويتحقق المظهر واللغتان.

## الإغلاق

حدود التنظيم والوصول متسقة مع الاشتراك والتشغيل وبقية النطاقات. الإغلاق التحليلي لا يعني اختبار إنتاج؛ تعتمد الأسعار وشروط الخدمة والتكاملات وخطة التشغيل قبل الإطلاق، وتتحقق الرحلات والصلاحيات عند التنفيذ.
