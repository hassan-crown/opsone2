# النطاق 03: مسارات التشغيل والمهام

**الحالة: مغلق مبدئيًا بعد مراجعة ارتباطاته؛ الاعتماد النهائي بعد مراجعة الرحلات.**

## الهدف والحدود

تجهز المساحة بالمسار الافتراضي منشورًا (خمس مراحل: القياس والمعاينة، والتصميم والعرض، والاتفاق والدفعة الأولى، والتصنيع، والتركيب والتسليم؛ والقياس والتصميم فيه عند الحاجة)؛ اختيار قالب بداية آخر صالح ومهيأ بصلاحية P-21 يستبدل المنشور فور التأكيد للطلبات الجديدة فقط، والتخطي يبقي الافتراضي فلا يتوقف فتح الطلبات. لا يتطلب القالب أقسامًا أو موظفين غير موجودين؛ يبدأ الإسناد بمسؤول الطلب أو صندوق متابعة معلوم. تستكمل الأهلية أو المتطلبات الخاصة بالفعل عند تنفيذه دون اختلاق اعتماد أو قبض أو تجاوز ضوابط السلامة. الطلبات الجارية لا تتأثر، ووجود مسودة تعديل يحتاج حسمًا صريحًا قبل استبدال القالب.

تنظيم طلبات المنتجات حسب الطلب بمسار تشغيل واحد للمنشأة، يخدم جميع أنشطتها. المرحلة حاوية لإجراءات جاهزة يوفرها النظام، وليست نوعًا ثابتًا مثل «مرحلة تصميم». يبدأ المسار بإنشاء الطلب، وتبقى جميع أعماله مرتبطة برقمه. طلبات المنتجات الجاهزة لها دورة مستقلة مختصرة.

## أجزاء النظام ضمن النطاق

| الجزء | ما يشمله |
| --- | --- |
| مسار المنشأة | اختيار قالب بداية واحد، وتعديل المراحل والإجراءات والإسناد ونشر التعديل. |
| المراحل والإجراءات | الترتيب والمسؤول والإجراءات المطلوبة والاختيارية وشروط الإتمام والمدة المستهدفة. |
| المهام | مهامي وصندوق القسم وغير المسند وإعادة الإسناد. |
| تشغيل الطلب | التقدم والإيقاف والاستئناف وإعادة العمل والسبب المانع والخطوة التالية. |
| حماية الترابط | منع إعدادات متعارضة، وحفظ إعداد الطلب الجاري وسجل التغييرات. |

## ارتباطات تتبع نطاقات أخرى

- **التنظيم والوصول:** الموظفون والأدوار والفروع والأقسام والصلاحيات؛ يستخدمها المحرك للإسناد والمتابعة دون توسيع الوصول.
- **العميل والكتالوج والطلب:** سجل الطلب وقياساته وبنوده ومواصفاته؛ إنشاء الطلب أول خطوة، دون اشتراط سعر أو قياس أو عرض.
- **العروض والعقود والاعتمادات:** إعداد المستند وموافقة العميل أو توثيق الموافقة الخارجية؛ يقرأ المحرك النتيجة المطلوبة.
- **المالية:** الاستحقاقات والتحصيل وسندات القبض والاسترداد والفاتورة الخارجية؛ المحرك يتحقق من النتيجة ولا ينشئ محاسبة مستقلة.
- **المخزون والتوريد والتسليم:** المشتريات والاستلام والحجز والصرف والتسليم الجزئي؛ تبقى العمليات في سجلاتها الأصلية.
- **مساحة العميل والإشعارات والتدقيق:** حالة عامة مناسبة للعميل وإجراؤه التالي، مع إشعارات حسب المسؤول والصلاحية وسجل للقرارات. يستخدم تطبيق العملاء لاحقًا الخدمات نفسها.

## بناء المسار

- للمنشأة مسار مخصص نشط واحد لجميع الأنشطة والفروع؛ لا يختار الموظف قالبًا عند فتح كل طلب، ولا يكون عدد المسارات ميزة باقة.
- قوالب البداية بدائل لتسهيل الإعداد فقط. تختار المنشأة واحدًا وتعدل أسماء مراحله وترتيبها وإجراءاتها ضمن الحدود النظامية. تغيير القالب لاحقًا يعامل كتعديل المسار، دون محو أعمال الطلبات الجارية.
- إنشاء الطلب بداية ثابتة لا تحذف. التحويل من اهتمام ينشئ الطلب مرة واحدة ويربطه به.
- المرحلة لها اسم داخلي، واسم مناسب للعميل عند إظهارها، ومسؤول متابعة، وإجراءات، ومدة مستهدفة اختيارية.
- داخل المرحلة تعرض الإجراءات في مجموعات ثابتة للتسهيل: المعلومات والقياس، الاتفاق والاعتماد، التنفيذ والتوريد، المالية، التسليم. هذه تصنيفات للإجراءات وليست أنواع مراحل أو أقسامًا وظيفية.
- تختار الجهة الإجراءات التي يوفرها النظام وتضبط المطلوب والاختياري والإسناد والمرجع؛ لا تنشئ إجراءً جديدًا أو حقولًا أو قواعد برمجية للمحرك.
- يمكن جمع إجراءات مختلفة في المرحلة نفسها. ترتب الإجراءات المرتبطة منطقيًا، وتتاح المستقلة معًا؛ لا يلزم تحرير أسهم أو علاقات يدوية.
- الإجراء الخاص بطلب بعينه يحدد انطباقه من خيار واضح مثل «يحتاج قياسًا» أو «يحتاج تصميمًا». المطلوب المشروط يطبق عند الحاجة فقط، ويظهر الباقي «غير مطلوب». لا يوجد محرر شروط عام، ولا إسقاط يدوي غير مسجل لمتطلب قائم.

## الإجراءات المتاحة

| النتيجة المطلوبة لإتمامه | التصنيف والإجراء |
| --- | --- |
| حفظ المعلومات المطلوبة للطلب. لا يلزم اكتمالها عند فتحه. | المعلومات: تثبيت الاحتياج والمواصفات |
| حفظ قياسات العمل والمرفقات المطلوبة، عند حاجة الطلب للقياس. | القياس: تسجيل القياسات |
| رفع التصميم الجاهز للمراجعة عند حاجة الطلب له. | التصميم: إعداد التصميم |
| حفظ المستند المطلوب داخل الطلب؛ إعداده لا يعني موافقة العميل. | الاتفاق: إعداد عرض سعر أو عقد |
| موافقة العميل على المستند المحدد، أو تسجيل المخول موافقته الخارجية مع إثباتها. | الاعتماد: موافقة على عرض أو تصميم أو عقد |
| إنجاز العمل وإرفاق ما يطلبه الإجراء. تتاح تسمية المهمة مثل تصنيع أو فحص أو تركيب، دون تغيير معناها النظامي. | التنفيذ: مهمة عمل |
| تحقق النتيجة المحددة من سجل المشتريات أو الاستلام المرتبط بالطلب. | التوريد: متابعة شراء أو استلام |
| تحصيل المبلغ أو النسبة المحددة من استحقاق مرتبط بالطلب. | المالية: تحقق التحصيل |
| وجود المستند، ومراجعته إن كانت مطلوبة؛ مثل فاتورة صادرة من نظام خارجي. | الوثائق: إرفاق مستند مطلوب |
| تسجيل ما سلم فعليًا وإثباته؛ الجزئي لا يكمل الباقي. | التسليم: تسجيل تسليم |

لكل إجراء حقول ونتيجة وصلاحيات ثابتة. ارتباطه المالي أو المخزني أو الاعتمادي لا يتغير بإعادة تسمية المرحلة.

## منع التعارض

- قبل نشر المسار يفحص النظام الترتيب والمراجع والصلاحيات واستحقاقات الوحدات، ووجود مسؤول متابعة، وإمكان تنفيذ كل إجراء مطلوب.
- لا يطلب اعتماد مستند قبل وجوده، ولا تحصيل نسبة قبل معرفة قيمتها، ولا استلام شراء دون مرجع، ولا تسليم كميات تتجاوز المتاح للتسليم.
- يمكن إعداد التصميم واعتماده في المرحلة نفسها، لكن الاعتماد لا يتاح قبل تجهيز التصميم. وإذا سبقه في مرحلة سابقة يرفض نشر الإعداد ويشرح التصحيح.
- يسمح بتكرار إجراء عند وجود غرض مختلف، مثل قياس أولي ونهائي أو دفعة أولى وأخيرة. يحدد المرجع الصحيح لكل مرة؛ لا يكرر التحصيل أو الاستلام أو التسليم.
- لا يمكن تفعيل إجراء تابع لوحدة غير متاحة للمنشأة. قيود المنتجات الجاهزة لا تعطل أعمال المنتجات المخصصة أو خاماتها.
- التحقق من الإعداد يوضح الخطأ ومكانه وكيف يصلح. عند العمل يعاد التحقق من الشروط والصلاحية؛ تكرار النقر أو إشعار الدفع لا يكرر الأثر.

## العمل اليومي والإسناد

- للطلب مسؤول متابعة دائم. تصل أعمال المرحلة إلى قسم محدد أو موظف مؤهل بحسب الإعداد.
- الدور يحدد الموظفين المؤهلين، ولا يسند العمل لكل أصحاب الدور. يوزع مشرف القسم أعمال صندوقه، ودون أقسام يسندها المخول مباشرة.
- عند غياب الموظف المؤهل أو مسؤول القسم، يبقى العمل في «غير المسند» بمتابعة مسؤول الطلب ومدير المنشأة مع تنبيه. تعطيل موظف يمنع وصوله وإسناد أعمال جديدة إليه، ويحفظ أعماله لإعادة توزيعها.
- تعرض المهمة المطلوب والطلب والموعد والمرفقات الضرورية. صلاحية تنفيذها لا تكشف كامل ملف العميل أو المالية.
- إعادة الإسناد تحفظ السابق والجديد والسبب والوقت، دون إعادة تنفيذ العمل المنجز.

## الانتقال والإيقاف

- مرحلة رئيسية واحدة نشطة للطلب، ومهام مستقلة يمكن تنفيذها بالتوازي داخلها. لا يشمل المحرك تفرعات مفتوحة أو مسارات منفصلة لكل بند.
- تكتمل المرحلة بتحقق إجراءاتها المطلوبة والمنطبقة، ثم يختار المخول «إكمال المرحلة». الإجراءات الاختيارية لا تمنع الانتقال؛ المهمة المفتوحة الاختيارية تبقى تحت متابعة مسؤولها.
- تظهر دائمًا المرحلة الحالية والخطوة التالية والمانع والمسؤول، مثل «بانتظار دفع 5,000 ر.س» أو «بانتظار موافقة العميل على التصميم».
- إيقاف الطلب يحتاج سببًا ومسؤول متابعة، ويحفظ المرحلة والإنجاز. الاستئناف لا يعيد المواعيد من الصفر، وتبقى المعالجة المالية اللازمة متاحة.
- انتهاء التشغيل لا يعني سداد الرصيد. يظهر التنفيذ منتهيًا والمبلغ المتبقي بوضوح، ولا تسقط الالتزامات عند إقفال التشغيل أو إلغاء الطلب.

## الدفعات والموافقات والاستثناءات

- الاستحقاقات والتحصيلات محفوظة في المالية على الطلب. إجراء المرحلة يشير إلى الاستحقاق والمبلغ المطلوب، ولا ينشئ سجل دفع مكررًا.
- المخول بتأكيد التحصيل يستطيع تسجيل دفعة مستلمة مع المبلغ والتاريخ والطريقة وإثبات الاستلام؛ تحتسب فورًا، ويصدر سندها وتتحقق شروط المراحل المرتبطة بها دون مراجعة إضافية مفروضة.
- رفع العميل إيصال تحويل وحده يبقيه بانتظار تأكيد المخول. يحتسب المحصل الفعلي فقط، مع منع تكرار المعاملة؛ المبلغ الجزئي يحقق الشرط بقدر ما يغطي المطلوب.
- موافقة العميل الخارجية تسجل بواسطة المخول مع الإثبات على المستند المقصود، وتحتسب موافقة موثقة دون إجبار العميل على دخول حسابه.
- إذا لم يحدث التحصيل أو الاعتماد فعلًا، يبقى خيار «السماح بالمتابعة» منفصلًا للمخول، مع السبب والإثبات المناسب. يبقى المبلغ مستحقًا أو الاعتماد غير حاصل، ويظهر الاستثناء في السجل.
- لا يسمح الاستثناء بكشف بيانات جهة أخرى أو اختلاق تحصيل أو تجاوز الكميات المخزنية أو حذف الأثر التدقيقي.

## التعديل دون تعقيد النسخ

- لا توجد إدارة إصدارات عامة للعملاء والمهام والقياسات والمراحل. تحفظ تعديلات العمل العادية في سجل التغييرات.
- يحتفظ النظام بالمستند الذي وافق عليه العميل. إذا تغير محتوى التصميم أو العرض أو العقد الذي سبق اعتماده، يحفظ السابق ويطلب موافقة على البديل قبل استخدامه للعمل المتأثر. تعديل عنوان ملف أو ملاحظة داخلية لا يعيد طلب الموافقة.
- تحفظ إعدادات مسار الطلب عند إنشائه داخليًا. تعديل مسار المنشأة يطبق على الطلبات الجديدة؛ لا تظهر للتاجر قائمة إصدارات ليختار منها.
- في الطلب الجاري يمكن للمخول تعديل الأعمال القادمة التي لم تبدأ، ضمن إجراءات النظام وبعد فحص ارتباطاتها، مع السبب. تعديل أعمال مكتملة أو حذف مراجع مالية أو اعتمادات لا يتم ضمن تحرير المراحل.
- إعادة العمل تعيد فتح الإجراء المطلوب بسبب واضح، وتحفظ إنجازه السابق. تحدد الأعمال اللاحقة المتأثرة فقط وتوقف إتمامها لحين المعالجة؛ لا تعيد فتح الجميع أو تحصيل دفعات أو صرف مخزون تلقائيًا.

## وضوح الاستخدام

- الإعدادات: «مسار التشغيل» مباشرة، بمراحل مرتبة وإجراءات مصنفة، دون قائمة مسارات للجهة.
- الطلب: أين وصل، ما المطلوب، من المسؤول، وما الإجراء المتاح الآن. الأعمال المنجزة والتفاصيل تظهر عند الحاجة.
- المهام: مهامي وصندوق القسم وغير المسند بحسب الصلاحيات.
- العميل: محطات مناسبة له وإجراؤه التالي، دون ملاحظات داخلية أو تفاصيل الاستثناءات. الموعد المؤكد يميز عن المتوقع.
- النصوص والتحقق بالعربية والإنجليزية، وفق نظام التصميم، مع الاحتفاظ بالمدخلات عند الخطأ.

## الصلاحيات

صلاحيات مستقلة لتعديل المسار ونشره، وإسناد الأعمال وإعادة إسنادها، وتنفيذ الإجراءات وإكمال المراحل، والإيقاف والاستئناف وإعادة العمل، وتعديل الأعمال القادمة، وتسجيل الاعتماد الخارجي والتحصيل المؤكد والسماح بالمتابعة. تعديل المسار لا يمنح الصلاحيات المالية أو موافقات العميل.

## تعليق الإلغاء وتصحيح العمل

- طلب الإلغاء يعلق بدء أعمال جديدة غير قابلة للتراجع حتى قرار المخول، دون محو موعد مؤكد أو شراء سابق. قبول الإدارة يوقف الباقي ويحيل الالتزامات إلى نطاقاتها؛ المال المستلم لا يمنع القبول.
- مرحلة رئيسية واحدة نشطة. تصحيح إجراء سابق مكتمل يظهر مهمة مرتبطة وعلامة «مكتملة مع تصحيح مطلوب»، ولا يفتح مرحلة رئيسية ثانية أو يعيد تحصيلًا أو صرفًا. تزال العلامة عند إنجاز التصحيح، وتتوقف الأعمال المتأثرة فقط.

## مخططات العمليات الأساسية

مخططات BPMN لقراءة العمل بين المسؤولين والخدمات، وليست إعدادًا يحرره التاجر أو محركًا إضافيًا. المخطط مع جدول حالاته وحدة واحدة: يعرض الرسم القرارات الرئيسية، وتحدد الجداول النتائج الجزئية والتزامن والفشل والعدول. التكرار أو وصول حدث قديم يعالجان وفق ضوابط الترابط في الـ SRS، دون إعادة أثر. المربع إجراء، والدائرة بداية أو نهاية، والمعين قرار حصري أو توازٍ بعلامة الجمع.

### تقدم المخصص وتصحيح العمل

المعرف: الـ P01. البداية: فتح المخصص أو إتاحة مرحلة، مع استئناف بعد معالجة مانع. النتيجة: رقم طلب ثابت، ومرحلة رئيسية واحدة، ومتابعة للتسويات دون تكرار عمل.

التتبع: الـ SRS-WF-01 إلى SRS-WF-13، SRS-INT-01 وSRS-INT-07، M-06 وM-07 وM-23 وM-27.

الصلاحيات: الـ P-15، P-22 إلى P-28، P-35. لا يلزم جمعها في شخص واحد؛ كل فعل يتحقق من إذن صاحبه.

| رد أو تغيير بعد إكمال مرحلة | تفتح مهمة تصحيح أو مانع للجزء المتأثر؛ لا مرحلة رئيسية ثانية ولا محو للتاريخ. |
| إلغاء أو توقف أثناء التنفيذ | يفحص قبل كل أثر جديد؛ ينفذ مخطط P03، وتبقى التسوية وتوثيق ما وقع متاحين. |
| نهاية التشغيل مع دين | يظهر منتهي التنفيذ مع مستحق؛ الإقفال الشامل ينتظر حسم الالتزامات. |

## معايير القبول

- الـ **WF-01:** يبدأ الطلب بلا سعر، وتبقى قياساته وعروضه وعقوده ودفعاته على رقمه؛ تحويل الاهتمام لا يكرره.
- الـ **WF-02:** للمنشأة مسار مخصص واحد؛ إضافة مرحلة أو ترتيبها لا يتيح إجراءً جديدًا خارج القائمة النظامية.
- الـ **WF-03:** يمنع نشر اعتماد يسبق مستنده أو شرط مالي بلا مرجع صالح، مع رسالة تصحيح مفهومة.
- الـ **WF-04:** تسند المهمة لمؤهل وتبقى الأعمال غير المسندة تحت متابعة معلومة، دون توسيع الوصول.
- الـ **WF-05:** تحصيل المخول المثبت يحقق شرط الدفعة؛ إيصال العميل غير المؤكد لا يحققه، وإعادة الإشعار لا تكرر السند.
- الـ **WF-06:** تعديل تصميم معتمد يحفظ السابق ويطلب موافقة على البديل؛ تعديل ملاحظة داخلية لا يفعل ذلك.
- الـ **WF-07:** تعديل المسار لا يغير طلبًا جاريًا تلقائيًا؛ تعديل أعماله القادمة يمنع كسر ارتباطاته ويحفظ السبب.
- الـ **WF-08:** إعادة العمل لا تكرر تحصيلًا أو صرفًا، والتسليم الجزئي لا يكمل الباقي.
- الـ **WF-09:** السماح بالمتابعة لا يحول غير المدفوع إلى مسدد، وانتهاء التنفيذ لا يخفي الالتزام المالي.
