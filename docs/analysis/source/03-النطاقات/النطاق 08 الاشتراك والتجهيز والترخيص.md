# النطاق 08: الاشتراك والتجهيز والترخيص

**الحالة محدد تفصيليًا ضمن وثائق النظام؛ المدة تبدأ من تسليم المنصة.**

## الهدف والحدود

موقع اشتراك وشراء إلكتروني وحساب مشترك يتتبع طلبه، مع صندوق داخلي محدود للتجهيز والتراخيص. التجهيز تحت إشراف مسؤول السيرفر، دون لوحة SaaS شاملة أو إنشاء بيئات ذاتي أو خصم دوري تلقائي.

## أجزاء النظام ضمن النطاق

| الجزء | ما يشمله |
| --- | --- |
| الشراء والدفع | الباقات والسعر والمدة والشروط وحساب المشترك ومعاملات دفع الشركة. |
| حساب المشترك | الطلبات والمدفوعات والمستندات وبيانات التجهيز والحالة والرابط وتواريخ الخدمة، والتجديد والترقية والإضافات، والإقرار بالتسلم. |
| صندوق التشغيل | الإسناد وبيئة الاستضافة وخطوات التجهيز والتعثر والاستئناف والتسليم. |
| الترخيص | القدرات والحدود والتوقيع وتجهيز غير مفعل ثم تفعيل مرتبط بالتسليم. |
| دورة الخدمة | التجديد والترقية والتخفيض والتراجع والسماح والتصفية والقراءة والاحتفاظ. |

## ارتباطات تتبع نطاقات أخرى

- **01:** بيانات الجهة والمالك ودعوة الدخول والتهيئة؛ تستعمل البيانات المحفوظة دون إعادة إدخال.
- **02 و03 و06:** الطلبات والأعمال والشراء والكمية؛ نتائجها تحدد تصفية الجاهز.
- **05:** مالية عملاء التجار مستقلة عن دفع اشتراك OpsOne للشركة.
- **07 و09:** الموقع ومتابعة العميل والإشعارات والدعم والتدقيق والملفات.

## رحلة الشراء والتسليم

1. يختار التاجر الباقة والمدة ويثبت حسابه وبريده، ويحفظ بيانات الجهة والمسؤول والسعر والشروط.
2. يدفع عبر مزود الشركة؛ التأكيد الخلفي المطابق يسجل التحصيل مرة واحدة، ولا ينتظر اعتماد محاسب ثان للنتيجة الموثوقة.
3. يستكمل اسم المنصة والنطاق وبيانات المالك إن نقصت، ويتلقى تأكيد الدفع ومرجع الطلب وحالة «مدفوع بانتظار بيانات» (تظهر له «بانتظار بيانات منصتك») أو «جارٍ التجهيز».
4. يسند الفريق الطلب لمسؤول تشغيل وبيئة معتمدة. الكود منتج واحد بإصدار معلوم على البيئات المدارة، وقاعدة وملفات وأسرار معزولة لكل جهة، دون فروع كود للتجار.
5. يجهز المسؤول ويختبر القاعدة والملفات والنطاق والاتصال والدخول والنسخ والترخيص. تعاد المحاولة على الجهة نفسها دون تكرار المساحة أو الخصم.
6. تبقى «جاهز بانتظار التسليم» حتى إتاحة الرابط ودعوة آمنة وإشعار إرسال ناجح أو إقرار المشترك بالتسلم من حسابه. عندها تثبت واقعة التسليم وبداية المدة ونهايتها.
- يرى المشترك في حسابه أربع مراحل: الدفع، بيانات المنصة، التجهيز، التسليم. الحالتان «جاهز للتجهيز» و«يحتاج معالجة» داخليتان وتظهران له «جارٍ التجهيز». يلغي المشترك طلبه من حسابه قبل التسليم فقط، وبعده عبر الدعم.
- **مدة الاشتراك تبدأ من تسليم المنصة**؛ لا من الدفع أو بدء التجهيز أو رفع الترخيص. الدعوة تطلب تعيين كلمة المرور ولا ترسل كلمة مرور جاهزة. لا ينتظر العداد إكمال التهيئة بعد تسليم صحيح.
- النطاق الخاص يتطلب إثبات ملكية وإعدادًا صالحًا؛ يمكن استعمال نطاق افتراضي بديل بموافقة المشترك دون تعطيل التسليم.
- حساب المشترك المركزي مستقل عن هوية عملاء كل جهة. سجل الموقع هو مرجع الحالة والدفع، والبريد أو Notion وسيلة متابعة لا حالة موازية.

## المال والترخيص والتجديد

- أسعار الباقات ومددها وشروطها منشورة ومعتمدة قبل البيع، ولقطتها تثبت مع الشراء. فواتير الشركة من محاسبتها الخارجية.
- فشل الدفع يسمح بمحاولة على الطلب نفسه؛ المعلق لا يفترض فاشلًا. تحصيل زائد حقيقي يسجل ويعالج برد معلوم، ولا يضاعف المنصات أو المدة تلقائيًا.
- للترخيص توقيع ومعرف جهة ونشر وباقة وحدود ومدة ومرجع تفعيل. ترخيص التجهيز غير مفعل؛ تفعيل التسليم يوحد البداية والنهاية في السجل والترخيص.
- التجديد المسبق يمدد من نهاية الخدمة الحالية؛ إعادة الإتاحة بعد انقضاء الخدمة تبدأ من إعادة التسليم. نقل الاستضافة أو النطاق لا يعيد العداد.
- الإلغاء قبل التسليم يوقف التجهيز ويعالج مال الشركة حسب سياسة الشراء، دون حذف دفع أو رد ضمني.

## تغيير الباقة

- التجديد والترقية والإضافات يطلبها المشترك ويدفعها من حساب OpsOne. التخفيض وإزالة وحدة الجاهز يطلبهما المالك من إعدادات منصته لأنهما يحتاجان تصفية القائم.
- إزالة وحدة الجاهز توقف المتجر وإنشاءه وتأكيده فور تسجيل طلب المالك الصحيح، دون انتظار موافقة الفريق؛ تبقى تسوية القائم فقط.
- قائمة الموانع تشمل طلبًا غير محسوم أو شراءً متبقيًا أو تسليمًا أو مالًا أو ردًا أو نزاعًا أو معاملة معلقة. الدفع الذي بدأ قبل الإيقاف يعالج ضمن القائم. لكل مانع إجراء حسم مباشر أو رابط لوظيفته بحسب الصلاحية، مع المسؤول والحالة. تتابع المدفوعات الجارية آليًا عبر إشعار المزود أو الاستعلام الموثوق حيث يدعمه؛ التعثر أو النتيجة المجهولة يبقيان المانع مع إعادة محاولة ومتابعة للمخول، ولا يعدان فشلًا نهائيًا أو حسمًا مفترضًا.
- يطبق الهدف عند الحسم وجاهزية الترخيص وموعد السريان؛ لا حذف بيانات ولا واجهات جاهز بعد التعطيل. تبقى المستندات والتتبع والمالية العامة للمخول.
- يمكن التراجع قبل التنفيذ، واستعادة المتجر حسب حالته السابقة والترخيص. تخفيض الحدود العامة يحفظ القائم ويمنع زيادته، ولا يطرد مستخدمين أو يحذف فروعًا.

## الانتهاء والتشغيل

التنبيه قبل14 و7 أيام ويوم الانتهاء. سماح7 أيام ثم30 يومًا لإنهاء القائم دون جديد، ثم قراءة وتصدير حتى نهاية الاحتفاظ المتعاقد عليه. لا حذف تلقائي بسبب الترخيص، ولا احتفاظ مجاني غير محدد. التحديث موحد وترحيل القواعد وفحصها ونسخها منفصل لكل جهة.

## مخططات العمليات الأساسية

مخططات BPMN لقراءة العمل بين المسؤولين والخدمات، وليست إعدادًا يحرره التاجر أو محركًا إضافيًا. المخطط مع جدول حالاته وحدة واحدة: يعرض الرسم القرارات الرئيسية، وتحدد الجداول النتائج الجزئية والتزامن والفشل والعدول. التكرار أو وصول حدث قديم يعالجان وفق ضوابط الترابط في الـ SRS، دون إعادة أثر. المربع إجراء، والدائرة بداية أو نهاية، والمعين قرار حصري أو توازٍ بعلامة الجمع.

### إزالة الجاهز وتنزيل الباقة

المعرف: الـ P09. البداية: طلب مالك صحيح يزيل الجاهز، بعد عرض الهدف والمقابل والموعد. النتيجة: وقف الجديد فورًا، ثم عدول آمن أو تعطيل كامل بعد التصفية.

التتبع: الـ SRS-SUB-08 إلى SRS-SUB-11 وSRS-SAL-17 وSRS-INT-08، M-20.

الصلاحيات: الـ P-57، P-58، P-77. لا يلزم جمعها في شخص واحد؛ كل فعل يتحقق من إذن صاحبه.

| عدول أثناء الانتظار | يعود المتجر وفق حالته السابقة والترخيص الفعال، لا يفتح متجرًا كان معطلًا أصلًا. |
| تزامن عدول وتطبيق | أول قرار صحيح مثبت هو النافذ؛ لا فتح بعد تطبيق هدف غير مستحق للجاهز. |
| الهدف غير جاهز أو التاريخ لم يحن | يبقى انتظار واضح؛ لا إيهام بتنفيذ التخفيض أو حذف بيانات. |
| المخصص ومواده | لا تتأثر الطلبات والخامات المتتبعة وصلاحيات المالية العامة بتعطيل الجاهز. |

## المتطلبات والصلاحيات والحالات

التفصيل الملزم في متطلبات الـ SRS-SUB-01 إلىSRS-SUB-23، والصلاحيات الـ P-73 إلىP-78 وP-86 إلىP-90، وآلات الحالات الـ M-18 وM-19 وM-20 وM-29 وM-30.
اختبارات الإقفال: دفع مكرر لا يكرر الخدمة؛ تعثر التجهيز لا يضيع المال؛ بيانات ناقصة لا تجهز عشوائيًا؛ فشل التسليم لا يبدأ المدة؛ نجاح التسليم يبدأها مرة واحدة؛ التخفيض يحسم الموانع ولا يعطل المخصص.
