# مصدر هذه الملفات

نسخة خام للقراءة فقط من حزمة وثائق تحليل OpsOne (`OpsOne-Documents`) كما سلّمها مالك المنتج:

- الأصل: مجلد `OpsOne-Documents` المرفق بجلسة التخطيط (نسخة عمل مؤقتة لدى جلسة المدير).
- تاريخ المراجعة المذكور في الفهرس: 2026-10-22.
- تاريخ النسخ: 2026-10-27، بأداة `ditto` مع الحفاظ على أسماء الملفات العربية (UTF-8).
- البصمات: `CHECKSUMS.sha256` (مسارات نسبية لهذا المجلد، `shasum -a 256 -c CHECKSUMS.sha256`). محسوبة بعد توحيد نهايات الأسطر إلى LF وفق `.gitattributes`؛ الملفات النصية في الحزمة الأصلية بنهايات CRLF.

## ما يوجد هنا

| المسار | المحتوى |
| --- | --- |
| `الفهرس.md` | فهرس الحزمة وملخص مراجعة الترابط |
| `01-إدارة المشروع/` | مرجع تنفيذ المشروع، والباقات وحدود الاستخدام |
| `02-وثائق التحليل/` | BRD، SRS، مصفوفة الصلاحيات (P-xx)، الحالات والانتقالات (M-xx) |
| `03-النطاقات/` | وثائق النطاقات 01–09 |
| `04-مخططات العمليات/` | مخططات P01–P09 (BPMN وSVG وPNG) ودليلها |

لا تعدّل هذه الملفات؛ عند تحديث الحزمة أعد نسخها وحدّث البصمات. القرارات المأخوذة منها تُسجَّل في `docs/decisions/`.
