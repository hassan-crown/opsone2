# مخططات العمليات الأساسية

تاريخ المراجعة: 22 أكتوبر 2026

نماذج أعمال بصيغة BPMN 2.0.2، غير تنفيذية. المرجع المعتمد هو وثائق Notion للنطاقات ومتطلبات النظام والصلاحيات والحالات. الصور للقراءة، والملفات ذات الامتداد bpmn للتحرير بأداة متوافقة. صلاحية الصيغة لا تعني اجتياز اختبارات نظام منفذ.

مرجع ترميز BPMN: https://www.omg.org/spec/BPMN/2.0.2/About-BPMN/

## إزالة الجاهز وتنزيل الباقة

المعرف: P09

وثيقة النطاق: [النطاق 08 الاشتراك والتجهيز والترخيص](../03-%D8%A7%D9%84%D9%86%D8%B7%D8%A7%D9%82%D8%A7%D8%AA/%D8%A7%D9%84%D9%86%D8%B7%D8%A7%D9%82%2008%20%D8%A7%D9%84%D8%A7%D8%B4%D8%AA%D8%B1%D8%A7%D9%83%20%D9%88%D8%A7%D9%84%D8%AA%D8%AC%D9%87%D9%8A%D8%B2%20%D9%88%D8%A7%D9%84%D8%AA%D8%B1%D8%AE%D9%8A%D8%B5.md)

المراجع: SRS-SUB-08 إلى SRS-SUB-11 وSRS-SAL-17 وSRS-INT-08، M-20

| الحالة | المعالجة |
| --- | --- |
| طلب بلا صلاحية أو هدف صالح | يرفض قبل غلق المتجر؛ يعرض الأثر والسعر وموعد السريان للمالك. |
| سلة أو رابط سابق | لا يبدأ شراء جديد؛ الدفع الذي بدأ قبل الطلب يظل قائمًا حتى حسمه. |
| دين أو رد أو نزاع أو شراء | يبقى مانعًا ظاهرًا من مصدره، ولا يسقط بتغيير اسم الحالة إلى مغلق. |
| مرتجع أو تسليم جزئي | تحسم الكميات والمال؛ لا حذف التاريخ أو فك مخزون مصرف. |
| عمولة موظف تاريخية | تبقى في المالية العامة ولا تمنع وحدها تنزيل الجاهز؛ تسويات مبيعات العميل يجب حسمها. |
| عدول أثناء الانتظار | يعود المتجر وفق حالته السابقة والترخيص الفعال، لا يفتح متجرًا كان معطلًا أصلًا. |
| تزامن عدول وتطبيق | أول قرار صحيح مثبت هو النافذ؛ لا فتح بعد تطبيق هدف غير مستحق للجاهز. |
| الهدف غير جاهز أو التاريخ لم يحن | يبقى انتظار واضح؛ لا إيهام بتنفيذ التخفيض أو حذف بيانات. |
| المخصص ومواده | لا تتأثر الطلبات والخامات المتتبعة وصلاحيات المالية العامة بتعطيل الجاهز. |
