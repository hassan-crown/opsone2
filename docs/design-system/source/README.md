OpsOne نظام واحد لإدارة العمليات: لوحة الموظفين، والموقع، ومساحة العميل. هذا النظام مرجعها الموحد. الواجهة **هادئة وواضحة**: أسطح بيضاء أو كحلية عميقة، ولون إجراء واحد، وتسلسل بالوزن والحجم قبل اللون، ولا زخرفة. أي شاشة يجب أن تُقرأ في نظرة ويُنجز عملها اليومي دون زحام.

## المبادئ

1. **لون واحد للفعل.** الأخضر المزرق `brand` للإجراءات والتحديد والروابط فقط. الكهرماني `highlight` للتمييز وحده. الألوان الأخرى للحالات.
2. **التسلسل بالوزن والحجم قبل اللون.** العنوان أثقل وأكبر، والثانوي `text-weak`، ولا نص ملوّن للتجميل.
3. **حدود لا ظلال.** الأسطح تُفصل بحد `stroke-weak`؛ الظل `shadow-raised` للنوافذ والدُّرج فقط.
4. **كل حالة مكتوبة.** التحميل والفراغ والخطأ والتعطيل لها مكوّن وكلمات، ولا يُحمل معنى باللون وحده.
5. **العربية أولًا والإنجليزية مساوية.** كل مكوّن يعمل RTL وLTR، فاتحًا وداكنًا، على الجوال والحاسوب.
6. **خيارات قليلة.** أربعة أنواع أزرار، ستة ألوان شارات، سلمان للخط، عشر مسافات. إن احتجت خارجها فالأرجح أن التصميم يحتاج تبسيطًا.

## المحتوى والنبرة

- خاطب المستخدم مباشرة بجمل قصيرة مهنية ودودة: «سيتواصل معك الفني قبل الزيارة بيوم واحد.» بلا تعجب، ولا إيموجي، ولا مبالغة.
- الأزرار أفعال تقول ما سيحدث: «حفظ الطلب»، «جدولة موعد التركيب»، «تصدير». لا «موافق» ولا «إرسال» مجردة.
- رسائل الخطأ: ما الذي تعذّر + ما العمل: «تعذّر حفظ الدفعة. تحقق من المبلغ وحاول مرة أخرى.» ورسائل التحقق تقول المطلوب: «يجب أن يكون المبلغ أكبر من صفر.»
- الحالات بأسماء ثابتة في كل المنتجات: مسودة، بانتظار الموافقة، قيد التصنيع، مكتمل، ملغى.
- التسميات بلا نقطتين: «رقم الجوال» لا «رقم الجوال:». الإنجليزية بحالة الجملة: “Save order”, “Phone number”.
- الأرقام والمبالغ بأرقام لاتينية في الواجهتين؛ التواريخ النسبية للحديث («قبل ٥ دقائق») والكاملة للسجلات.

## الألوان

ثلاثة ثيمات: `light` (الأول، والافتراضي) و`dark` و`contrast` للتباين العالي (فاتح، كل نص 7:1 على الأقل والأسطح مفصولة بحدود 3:1). استخدم **رموز الأدوار** دائمًا؛ اللوحات الخام (`teal-*`، `ink-*`، `amber-*`) مرجع لا تُستعمل مباشرة.

| الدور | الرمز | ملاحظة |
| --- | --- | --- |
| الصفحة | `background` | فوقها `surface` للبطاقات والجداول والقائمة |
| النوافذ والدُّرج | `raised` + `shadow-raised` | |
| السطح الثانوي | `fill` | رؤوس الجداول، الحقل المعطّل |
| المرور | `hover` | |
| النص | `text-strong` / `text-weak` / `text-placeholder` | الإرشاد على `field` فقط |
| الحدود | `stroke-weak` الفواصل · `stroke` الأسطح · `stroke-control` الحقول | |
| الإجراء | `brand` → `brand-hover` → `brand-active`، والنص عليه `on-brand` | `on-brand` أبيض في الفاتح وداكن في الداكن |
| التحديد الخفيف | `brand-subtle` مع `brand-subtle-text` | |
| التركيز | `focus` | |
| التمييز | `highlight` مع `on-highlight`، و`highlight-text` | ليس للإجراءات |
| الحالات | `success-*` · `warning-*` · `danger-*` · `info-*` · `neutral-*` (نص `-text` على `-bg`) | |
| الخطر | `danger` مع `on-danger` | زر الحذف |

- المعلومة `info-text` زرقاء ومنفصلة عن لون الإجراء عمدًا: لا تستخدم `brand` لرسالة.
- النجاح والخطأ يفترقان في الإضاءة قليلًا فقط؛ لذلك تحمل كل حالة كلمة وأيقونة دائمًا.
- كل نص في جداول الأدوار يحقق 4.5:1 على الأسطح المذكورة في ملاحظته بالثيمين، والحدود والتركيز 3:1. الاستثناء المعروف من المرجع: `highlight` رسوميًا 2.9:1 على الأبيض، فلا يُترك وحده.

## الخطوط

عائلة واحدة للعربية واللاتينية: **IBM Plex Sans Arabic** مع **IBM Plex Sans** للصفحات الإنجليزية (`--font-latin`)، و**IBM Plex Mono** للأرقام المرجعية. الملفات في `fonts/` بالأوزان 400 و500 و600 و700.

سلمان بالقيم نفسها في المرجع (حجم / سطر / وزن):

| الدور | لوحة الموظفين | البوابة والموقع |
| --- | --- | --- |
| عنوان رئيسي للموقع | — | `site-display` 40/56/700 |
| عنوان الصفحة | `panel-title` 24/36/600 | `site-title` 32/44/700 |
| عنوان قسم | `panel-section` 20/30/600 | `site-section` 24/36/600 |
| عنوان فرعي / نافذة | `panel-subtitle` 16/26/600 | `site-subtitle` 20/30/600 |
| النص | `panel-body` 14/24/400 | `site-body` 16/28/400 |
| الحقول والأزرار | `panel-control` 15/24/500 | `site-control` 16/24/500 |
| التسميات ورؤوس الجداول | `panel-label` 14/20/500 | `site-label` 14/20/500 |
| ملاحظة صغيرة (الحد الأدنى) | `panel-caption` 13/20/400 | `site-caption` 14/22/400 |

- المكونات تستخدم سلم اللوحة افتراضيًا. ضع `data-surface="site"` على جذر الموقع ومساحة العميل فتنتقل كلها إلى سلم البوابة.
- لا تباعد سالب بين الحروف العربية، وارتفاع سطر النص لا يقل عن 1.6.
- 600 للعناوين والعنصر المحدد، 500 للتسميات والأزرار، 400 للنص. لا 300 ولا مائل في العربية.
- الأرقام المرجعية بالخط الثابت ومعزولة LTR (`Ref`)، والمبالغ بأرقام لاتينية ثابتة العرض (`Amount`).

## المسافات والتخطيط

- سلم 4px: `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-5` 20 · `space-6` 24 · `space-8` 32 · `space-10` 40 · `space-12` 48 · `space-16` 64. لا قيم بينها.
- الحشوات: البطاقة والنافذة `space-6` (و`space-4` على الجوال)، الحقل `space-3` أفقيًا، الزر `space-5`. بين الحقول `space-4` عموديًا و`space-5` في الشبكة، وبين الأقسام `space-8`.
- الارتفاعات: كل عنصر تفاعلي `control-height` 44px (هدف لمس كافٍ)، والمضغوط `control-height-sm` 36px على الحاسوب فقط.
- الزوايا: `radius-sm` 6 للشارات، `radius-md` 8 للأزرار والحقول والتنبيهات والقائمة، `radius-lg` 12 للبطاقات والجداول والنوافذ، `radius-full` للمؤشر العددي والصورة الرمزية والمفتاح ودوائر المراحل.
- الشاشات: الجوال أولًا. من `bp-md` 768px شبكات بعمودين وجداول كاملة، ومن `bp-lg` 1024px قائمة جانبية ثابتة. أقصى عرض للمحتوى `content-max` 1200px وللقراءة `reading-max` 720px.
- استخدم الخصائص المنطقية دائمًا (`margin-inline-start`، `inset-inline-end`، `text-align: start`) فيعمل الاتجاهان دون نسختين.

## الحركة

قليلة ووظيفية: 120ms لتغير الألوان عند المرور والتركيز، و200ms لامتلاء شريط التقدم، ولا حركة لدخول النوافذ والقوائم وخروجها. عند «تقليل الحركة» تتوقف النبضات ويبطؤ المؤشر.

## الأيقونات

Lucide الخطية (رخصة ISC) بسماكة 1.75 وشبكة 24، عبر المكوّن `Icon` أو ملفات مجموعة **Icons**. أيقونة بجانب نص لا بدلًا منه، إلا في زر مربع له `aria-label`. الاتجاهية تنعكس في RTL.

## الشعار

استخدم الملفات الأصلية فقط (مجموعة **Logos**) أو المكوّن `Logo`. الشعار الكامل على الفاتح `opsone-logo.svg` وعلى الداكن `opsone-logo-reversed.svg`؛ العلامة وحدها للمساحات الضيقة؛ `quiet` حين يُراد للشعار حضور أخف (التذييلات والمستندات)؛ أحادي اللون للطباعة والختم. أيقونة التطبيق والمفضلة في مجموعة **App icons**. لا تعِد رسمه أو تلوينه.

## الاستخدام في React

حمّل `tokens.css` ثم `components/bundle.css`، وReact 18، ثم `components/bundle.js` فيصبح كل شيء على `window.OpsOne` (أو انسخ `components/src/` إلى مشروعك). اضبط الجذر مرة واحدة:

```html
<html lang="ar" dir="rtl" data-theme="light">
<body data-surface="panel">   <!-- أو data-surface="site" للموقع ومساحة العميل -->
```

```js
const { AppShell, PageHeader, Button, Table, Pagination, ToastProvider, useToast, setTheme, setLanguage } = window.OpsOne;
setTheme('system');   // 'light' | 'dark' | 'contrast' | 'system'
setLanguage('ar');    // يضبط lang وdir
```

لفّ التطبيق مرة واحدة بـ `ToastProvider` ليعمل `useToast()`. النصوص المساعدة الداخلية (جارٍ التحميل، إغلاق، السابق والتالي، تخطَّ إلى المحتوى…) تتبع `lang` في الصفحة، أو `LocaleProvider` لجزء منها.
