# PageHeader

رأس الصفحة: العنوان (h1) ووصف قصير وإجراءات الصفحة، يلتف على الجوال.

**يقدّم المستهلك:** `title`، واختياريًا `description` و`actions` (زر رئيسي واحد وثانوي أو اثنان) و`back` (زر `ghost` بأيقونة `arrow-left`).

- عنوان واحد لكل صفحة بنمط `panel-title` (24/36/600)، و`site-title` في البوابة.
- على الجوال تمتد الإجراءات بعرض الشاشة.
