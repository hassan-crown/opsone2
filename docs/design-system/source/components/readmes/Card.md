# Card

حاوية بيضاء بحد خفيف وزوايا 12px تجمع محتوى مرتبطًا في الصفحة.

**يقدّم المستهلك:** المحتوى، واختياريًا `title` (يصبح عنوان القسم المقروء)، و`description`، و`actions` في رأسها، و`footer` لأزرار الحفظ.

- الحشوة 24px على الحاسوب و16px على الجوال. `padding="none"` لجدول أو قائمة تملأ البطاقة.
- البطاقات تُفصل بالحد `stroke-weak` لا بالظل، والمسافة بينها `space-6`.
- لا تضع بطاقة داخل بطاقة، ولا تلوّن البطاقة أو حافتها لتمييزها: استخدم شارة أو تنبيهًا.
