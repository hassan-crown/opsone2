# SearchField

حقل بحث بأيقونة وزر مسح، لأعلى الجداول والقوائم.

**يقدّم المستهلك:** `label` (يُخفى بصريًا افتراضيًا ويبقى مقروءًا)، و`value`/`onChange` أو `defaultValue`، واختياريًا `onSearch` (Enter ومسح) و`placeholder` و`loading`.

- `placeholder` يقول ما يُبحث فيه: «رقم الطلب أو اسم العميل أو الجوال».
- النتائج تتحدث أثناء الكتابة بتأخير 300ms من جهة المستهلك؛ `loading` يبدّل الأيقونة إلى مؤشر.
- Esc يمسح النص. لا نتائج؟ اعرض `EmptyState` بعنوان «لا توجد نتائج مطابقة» وزر «مسح البحث».
