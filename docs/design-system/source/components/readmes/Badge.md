# Badge

شارة حالة قصيرة بجانب سجل: كلمة أو كلمتان، بنص الحالة على خلفيتها الخاصة.

**يقدّم المستهلك:** النص و`tone`.

| الحالة | `tone` | أمثلة |
| --- | --- | --- |
| نجاح | `success` | مكتمل، مدفوع |
| معلومة | `info` | قيد التصنيع، مجدول |
| تحذير | `warning` | بانتظار الموافقة |
| خطأ | `danger` | ملغى، مرفوض |
| محايد | `neutral` | مسودة |
| تصنيف | `brand` | مطبخ، خزانة |

- الكلمة هي الحالة، واللون يساندها: لا تستخدم شارة بلا نص.
- خرّط كل حالة إلى `tone` واحد في كل المنتجات (اللوحة والموقع ومساحة العميل).
- الشارات لا تُنقر؛ للتصفية استخدم أزرارًا.
