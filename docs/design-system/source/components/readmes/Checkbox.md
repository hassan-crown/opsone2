# Checkbox

خانة اختيار أصلية بلون الإجراء، لخيار مستقل يُفعَّل أو يُلغى.

**يقدّم المستهلك:** `label`، و`checked`/`onChange` أو `defaultChecked`، واختياريًا `hint` و`error` و`disabled`.

- السطر بارتفاع 44px والتسمية كلها قابلة للنقر.
- اكتب التسمية بصيغة إيجابية: «إرسال إشعار للعميل» لا «عدم إرسال…».
- للتأثير الفوري على النظام استخدم زرًا لا خانة بلا حفظ.
