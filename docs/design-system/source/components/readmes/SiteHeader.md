# SiteHeader

رأس الموقع ومساحة العميل: الشعار، وروابط قليلة، وإجراءات الحساب، ويتحول إلى دُرج على الجوال والجهاز اللوحي.

**يقدّم المستهلك:** `nav` (`{id, label, href}`)، و`activeId`، واختياريًا `onNavigate` و`actions` (اللغة، الدخول، الصورة الرمزية) و`brand`.

- ضع `data-surface="site"` على جذر الصفحة، والمحتوى داخل `<main id="o1-main">` بعرض `content-max`.
- من ثلاثة إلى خمسة روابط بكلمة أو كلمتين؛ الرابط الحالي بخط سفلي `brand` و`aria-current="page"`.
- تحت 1024px تنتقل الروابط إلى دُرج يحبس التركيز ويغلق بـ Esc، وتحت 768px تنتقل الإجراءات إليه أيضًا.
- لوحة الموظفين تستخدم `AppShell` لا هذا الرأس.
