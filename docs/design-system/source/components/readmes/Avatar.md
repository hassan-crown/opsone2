# Avatar

صورة رمزية دائرية للأشخاص: صورة إن وجدت، وإلا الحرف الأول من الاسم الأول والأخير.

**يقدّم المستهلك:** `name`، واختياريًا `src` و`size` (`sm` 32 · `md` 40 · `lg` 56) و`decorative` حين يظهر الاسم بجانبها.

- الحروف بلون `brand-subtle-text` على `brand-subtle` لكل الأشخاص؛ لا ألوان عشوائية.
- «ال» التعريف تُتجاهل عند أخذ الحرف، والحرفان العربيان لا يتصلان.
