# ToastProvider

إشعار مؤقت لنتيجة إجراء تم للتو («تم حفظ الطلب»)، يظهر في زاوية الشاشة ولا يقطع العمل.

**يقدّم المستهلك:** `ToastProvider` مرة واحدة حول التطبيق، ثم `const toast = useToast()` و`toast.show({ tone, title?, message, action?, duration? })`؛ و`toast.dismiss(id)`.

- `tone`: `success` (افتراضي) · `info` · `warning` · `danger`. النجاح والمعلومة يختفيان بعد 5 ثوانٍ ويتوقف العدّ عند المرور أو التركيز؛ الخطأ وما فيه `action` يبقيان حتى يُغلقا.
- يُعلن بهدوء (`role="status"`)، والخطأ فورًا (`role="alert"`). ثلاثة إشعارات كحد أقصى.
- للنتائج فقط: لا تضع فيه سؤالًا أو قرارًا (`Dialog`)، ولا خطأ تحقق (تحت الحقل)، ولا رسالة دائمة (`Alert`).
- إجراء واحد قصير كحد أقصى، مثل «تراجع».
- يظهر في نهاية السطر أسفل الشاشة (يسار في العربية)، وبعرض الشاشة على الجوال.
