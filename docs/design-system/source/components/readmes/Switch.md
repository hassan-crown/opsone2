# Switch

مفتاح تشغيل لإعداد يسري فورًا دون زر حفظ: الإشعارات، الموافقات التلقائية.

**يقدّم المستهلك:** `label`، و`checked`/`onChange` أو `defaultChecked`، واختياريًا `description` و`disabled`.

- `role="switch"` مع `aria-checked`؛ Space وEnter يبدّلان. السطر 44px والتسمية قابلة للنقر.
- المسار `stroke-control` مطفأ و`brand` مشغّل، والمقبض ينتقل نحو نهاية السطر عند التشغيل.
- داخل نموذج له زر حفظ استخدم `Checkbox` بدلًا منه.
- التسمية تصف الشيء لا الحالة: «إشعارات واتساب للعميل» لا «تشغيل/إيقاف».
