# Counter

مؤشر عددي دائري بلون التمييز الكهرماني، للأعداد التي تنتظر انتباهًا.

**يقدّم المستهلك:** `value`، و`label` يقرأ المعنى كاملًا («3 طلبات بانتظار الموافقة») حين يقف الرقم وحده.

- بجانب عنصر قائمة أو تبويب أو عنوان؛ ليس للإجراءات (الكهرماني للتمييز فقط).
- ما فوق `max` (99) يظهر «99+».
- الرقم بلون `on-highlight` لأن `highlight` وحده 2.9:1 على الأبيض.
