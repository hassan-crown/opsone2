# Tooltip

تلميح قصير يظهر عند المرور أو التركيز، أساسًا لتوضيح الأزرار المربعة.

**يقدّم المستهلك:** `content` (نص قصير)، وعنصرًا تفاعليًا واحدًا داخله، واختياريًا `placement` (`top` · `bottom`).

- يُربط بالعنصر عبر `aria-describedby`؛ الاسم الأساسي للزر يبقى `aria-label`.
- لا يظهر باللمس، فلا تضع فيه معلومة لا توجد في مكان آخر، ولا روابط أو أزرار.
- يظهر بعد 400ms عند المرور وفورًا عند التركيز، ويختفي بـ Esc.
