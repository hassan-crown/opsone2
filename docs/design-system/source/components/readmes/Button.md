# Button

الزر لكل إجراء: رئيسي واحد في كل منطقة، وثانوي للبدائل، ونصي للإجراءات الخفيفة، وخطِر للحذف.

**يقدّم المستهلك:** النص (فعل واضح: «حفظ الطلب» لا «موافق»)، و`variant`، و`onClick` أو `type="submit"` أو `href`.

| الخاصية | القيم |
| --- | --- |
| `variant` | `primary` (افتراضي) · `secondary` · `ghost` · `danger` |
| `size` | `md` ارتفاع 44 (افتراضي) · `sm` «مضغوط 36» داخل الجداول وأشرطة الأدوات على الحاسوب |
| `icon` / `iconEnd` | اسم أيقونة أو عنصر |
| `iconOnly` | زر مربع؛ **يجب** معه `aria-label` |
| `loading` | يعرض المؤشر ويمنع النقر مع إبقاء التركيز (`aria-busy`) |
| `disabled` | يُعرض بـ `aria-disabled` فيبقى قابلًا للتركيز ويُقرأ سببه من النص المحيط |
| `block` | بعرض الحاوية (أزرار النماذج على الجوال) |

- الحالات: عادي `brand`، مرور `brand-hover`، ضغط `brand-active`، تركيز إطار `focus` بإزاحة 2px، معطّل `disabled-bg`.
- زر رئيسي واحد لكل نموذج أو نافذة. في النوافذ والنماذج يأتي الرئيسي في نهاية السطر (يسار في العربية)، والإلغاء قبله.
- لا تعطّل زر الحفظ لإخفاء الأخطاء: دعه يعمل واعرض رسائل التحقق.
- الخطِر للحذف النهائي فقط، ويسبقه تأكيد في `Dialog`.
