# DescriptionList

قائمة «تسمية: قيمة» لصفحات التفاصيل: بيانات العميل، ملخص الطلب.

**يقدّم المستهلك:** `items` (`{label, value, wide?}`)، واختياريًا `columns` (1 · 2 · 3، عمود واحد على الجوال دائمًا).

- القيمة الفارغة تظهر «—» لا فراغًا. الأرقام بـ `Ref`، والمبالغ بـ `Amount`.
- `wide` لقيمة طويلة كالعنوان أو الملاحظات.
- للتعديل انقل إلى نموذج أو زر «تعديل» في رأس البطاقة؛ لا حقول داخل القائمة.
