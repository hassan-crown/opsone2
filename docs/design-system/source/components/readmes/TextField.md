# TextField

حقل نصي بتسمية ظاهرة ونص إرشاد ورسالة تحقق، مبني على `Field` الذي يربط كل ذلك بالحقل تلقائيًا.

**يقدّم المستهلك:** `label` (دائمًا)، و`value`/`onChange` أو `defaultValue`، و`error` حين يفشل التحقق، واختياريًا `hint` و`required` و`optional` و`multiline` و`dir`.

- **التسمية دائمًا ظاهرة فوق الحقل.** نص الإرشاد (`placeholder`) مثال لا تسمية: «الاسم الكامل»، «05XXXXXXXX».
- الإلزام: `required` يضع `*` حمراء ويضبط `aria-required`. إن كانت أغلب الحقول إلزامية فعلّم الاختيارية بـ `optional` بدلها.
- التحقق: اعرض الخطأ بعد مغادرة الحقل أو عند الإرسال، لا مع كل ضغطة. الرسالة تقول المطلوب: «يجب أن يكون المبلغ أكبر من صفر.» وتظهر مع أيقونة، ويُربط بالحقل عبر `aria-describedby` و`aria-invalid`.
- عند الإرسال بأخطاء: انقل التركيز إلى أول حقل خاطئ.
- الأرقام والجوال والبريد والآيبان: `dir="ltr"` مع `inputMode` المناسب (`tel`، `decimal`، `email`) و`autoComplete`.
- المعطّل (`disabled`) للقيم التي لا يملك المستخدم تغييرها مع إبقائها مقروءة؛ و`readOnly` لقيمة يمكن نسخها.
- الحالات: عادي `stroke-control`، مرور `text-weak`، تركيز حد `brand` 2px مع هالة `focus-halo`، خطأ `danger-text`، معطّل `fill` مع `stroke-weak`.
- لحقل مخصص استخدم `Field` مباشرة وضع بداخله `Input` أو `Textarea` أو `Select` أو عنصرك الخاص مع `id` الممرر.
- في البوابة والموقع (`data-surface="site"`) يصبح نص الحقل 16px فلا يكبّر iOS الصفحة.
