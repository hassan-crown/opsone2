# Table

جدول بيانات بسطر عنوان خفيف وفواصل صفوف وحالات تحميل وفراغ وخطأ مدمجة، يتحول إلى بطاقات مكدسة على الجوال.

**يقدّم المستهلك:** `columns` (`{key, header, render?, align?, width?}`)، و`rows`، و`caption` (دائمًا؛ `captionHidden` لإخفائه بصريًا)، و`loading` و`empty` و`error` حسب الحالة، واختياريًا `onRowClick`.

- **تحميل:** `loading` يعرض صفوفًا هيكلية ويضبط `aria-busy`. **فراغ:** مرّر `EmptyState` مختصرًا في `empty` مع إجراء الإنشاء. **خطأ:** مرّر `EmptyState` بـ `tone="danger"` وزر «إعادة المحاولة» في `error`.
- أرقام الطلبات بـ `Ref` (بلون الرابط إن فتحت السجل)، والحالة بـ `Badge`، والمبالغ بـ `Amount` مع `align: 'end'` لتصطف.
- رؤوس الأعمدة كلمات قصيرة تُستخدم أيضًا تسميات في عرض الجوال (أقل من 768px). اجعل `header` نصًا.
- اجعل العمود الأول هو المعرّف، وضع الإجراءات في آخر عمود بزر `sm` أو `ghost`.
- إن ضاق الجدول عن عرضه على الحاسوب يمرّر أفقيًا ويصبح قابلًا للتركيز بلوحة المفاتيح.
- لا خطوط عمودية ولا تلوين متناوب للصفوف؛ المرور `hover` فقط.
