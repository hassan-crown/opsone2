# Skeleton

كتل هيكلية هادئة تحجز مكان المحتوى أثناء التحميل فلا تقفز الصفحة.

**يقدّم المستهلك:** `width` و`height` و`radius`، أو `lines` لفقرة. ضع `aria-busy="true"` واسمًا مقروءًا على الحاوية.

- طابِق شكل المحتوى الحقيقي وأبعاده تقريبًا.
- يتوقف النبض عند «تقليل الحركة».
- إن تجاوز التحميل عشر ثوانٍ فاعرض رسالة أو خطأ بدل الهيكل.
