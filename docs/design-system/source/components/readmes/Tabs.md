# Tabs

تبويبات تقسّم صفحة سجل واحد إلى أقسام متكافئة، والمحدد بخط سفلي بلون الإجراء.

**يقدّم المستهلك:** `tabs` (`{id, label, content?, count?, icon?, disabled?}`)، و`label` اسم المجموعة لقارئ الشاشة، و`value`/`onChange` أو `defaultValue`.

- لوحة المفاتيح: الأسهم تنتقل بين التبويبات باتجاه القراءة (في RTL السهم الأيسر = التالي)، و`Home`/`End` للأول والأخير.
- بين ثلاثة وستة تبويبات بكلمة أو كلمتين. على الجوال تمرّر أفقيًا.
- التبويبات للأقسام لا للخطوات: للتسلسل استخدم صفحات أو نموذجًا مقسّمًا.
- بدّل المحتوى فقط ولا تنقل الصفحة؛ إن كان لكل تبويب رابط فاحفظ `id` في عنوان الصفحة.
