# Progress

شريط تقدم لعملية لها مدة: رفع ملف، تجهيز تصدير.

**يقدّم المستهلك:** `value` (0–`max`)، أو لا شيء لتقدم غير محدد، و`label` يصف العملية، واختياريًا `showValue` و`tone="danger"`.

- يملأ من بداية السطر (اليمين في العربية). غير المحدد يتحرك بهدوء ويثبت عند «تقليل الحركة».
- للانتظار القصير غير المحدد داخل زر استخدم `Button loading`.
