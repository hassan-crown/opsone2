# Alert

تنبيه داخل الصفحة لرسالة تخص السياق الحالي: معلومة، نجاح، تحذير، أو خطأ.

**يقدّم المستهلك:** `tone`، والنص (جملة كاملة تقول ما حدث وما العمل)، واختياريًا `title` و`action` و`onDismiss`.

- النص دائمًا `text-strong` على خلفية الحالة، والأيقونة بلون الحالة: معلومة داخل دائرة، تحذير داخل مثلث، إغلاق داخل دائرة للخطأ، صح داخل دائرة للنجاح.
- الخطأ يُعلن فورًا (`role="alert"`)، والباقي بهدوء (`role="status"`). اعرض التنبيه عند وقوع الحدث لا قبله حتى يُقرأ.
- اكتب الخطأ بصيغة: ما الذي تعذّر + ماذا يفعل المستخدم: «تعذّر حفظ الدفعة. تحقق من المبلغ وحاول مرة أخرى.»
- أخطاء الحقول تحت الحقل نفسه (`TextField error`)، لا في تنبيه أعلى الصفحة؛ استخدم التنبيه لخطأ النموذج العام أو الخادم.
- لا تُكدّس أكثر من تنبيهين في الصفحة.
