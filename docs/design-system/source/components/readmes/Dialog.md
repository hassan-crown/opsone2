# Dialog

نافذة منبثقة تعتمد عنصر `dialog` الأصلي: تحبس التركيز، وتغلق بـ Esc، وتعطّل الصفحة خلفها.

**يقدّم المستهلك:** `open`، و`onClose`، و`title` (فعل أو سؤال واضح)، واختياريًا `description` و`children` و`footer` (الأزرار) و`size` (`sm` 400 · `md` 560 · `lg` 800).

- العنوان بنمط `panel-subtitle` 16/26/600، والرئيسي في نهاية التذييل والإلغاء قبله؛ على الجوال تتكدس الأزرار بعرض كامل والرئيسي في الأعلى.
- عند الإغلاق يعود التركيز تلقائيًا إلى العنصر الذي فتحها. ضع `data-autofocus` على أول حقل إن كانت النافذة نموذجًا.
- `dismissible={false}` فقط لعملية جارية لا يصح قطعها.
- للتأكيدات الخطرة: عنوان بصيغة سؤال («حذف الطلب ORD-1042؟») ووصف يذكر العاقبة وزر `danger` بفعل صريح («حذف الطلب»).
- لا نوافذ فوق نوافذ، ولا نماذج طويلة داخلها: انقلها إلى صفحة.
