# Amount

مبلغ مالي بأرقام لاتينية ثابتة العرض حتى تصطف الأعمدة، والعملة بلغة الواجهة.

**يقدّم المستهلك:** `value` (رقم)، واختياريًا `currency` (`SAR` افتراضيًا) و`decimals` (2) و`strong` للإجماليات.

- العربية: «18,450.00 ر.س»؛ الإنجليزية: «SAR 18,450.00». الرقم معزول LTR في الحالتين.
- في الجداول: `align: 'end'` على العمود.
- الإجمالي بـ `strong`؛ لا تلوّن المبالغ إلا السالب بـ `danger-text` مع إشارة السالب.
