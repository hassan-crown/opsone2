# Icon

أيقونات خطية من Lucide بسماكة 1.75 على شبكة 24، تأخذ لون النص المحيط (`currentColor`).

**يقدّم المستهلك:** `name` (من القائمة في المعاينة)، و`size` (20 افتراضيًا، 16 بجانب النص الصغير)، و`label` فقط إذا كانت الأيقونة تحمل معنى وحدها.

- الأيقونة زخرفية افتراضيًا (`aria-hidden`). إن كانت وحيدة داخل زر فضع `aria-label` على الزر لا على الأيقونة.
- سمِّ الأيقونات الاتجاهية بمعناها في LTR: `chevron-right` و`arrow-right` = «التالي/للأمام»، و`arrow-left` = «رجوع». هذه الأيقونات و`log-out` و`external-link` تنعكس تلقائيًا في RTL.
- أيقونة واحدة لكل فكرة في كل المنتجات: الطلبات `clipboard-list`، العملاء `users`، المواعيد `calendar`، الفواتير `receipt`، التصدير `download`.
- لا إيموجي في الواجهة، ولا أيقونات ملوّنة أو ممتلئة.
