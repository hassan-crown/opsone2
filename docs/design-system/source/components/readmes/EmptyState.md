# EmptyState

حالة الفراغ: ماذا يعني أن لا شيء هنا، وما الخطوة التالية.

**يقدّم المستهلك:** `title` (يصف الحالة)، و`description` (ما العمل)، و`action` (زر أو زران)، واختياريًا `icon` و`compact` و`tone="danger"` لحالة الخطأ.

- ثلاثة أنواع، لكل منها كلامه: لا بيانات بعد («لا توجد طلبات بعد» + «طلب جديد»)، لا نتائج للبحث («لا توجد نتائج مطابقة» + «مسح التصفية»)، تعذّر التحميل («تعذّر تحميل الطلبات» + «إعادة المحاولة»).
- أيقونة خطية واحدة في دائرة `fill`؛ لا رسومات توضيحية.
- `compact` داخل الجداول والبطاقات.
