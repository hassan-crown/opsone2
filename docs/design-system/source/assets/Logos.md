# Logos

الملفات الأصلية المعتمدة. لا تُعدَّل ولا يُعاد رسمها؛ في React استخدم المكوّن `Logo` (يرسم المسارات نفسها ويتبدّل مع الثيم).

- `opsone-logo.svg` — الشعار الكامل للخلفيات الفاتحة: العلامة `teal-600` و`ink-900`، والاسم `ink-900`.
- `opsone-logo-reversed.svg` — للخلفيات الداكنة: العلامة `teal-400` والمربعات بيضاء، والاسم `ink-25`.
- `opsone-logo-quiet.svg` — نسخة هادئة (مربعات `ink-200`) حين يُراد للشعار حضور أخف: التذييلات والمستندات، على الفاتح فقط.
- `opsone-mark.svg` / `opsone-mark-reversed.svg` / `opsone-mark-quiet.svg` — العلامة وحدها للمساحات الضيقة (24px على الأقل).
- `opsone-mark-mono-ink.svg` — حبر واحد `#0B1B33` للطباعة والختم على الفاتح. `opsone-mark-mono-white.svg` — أبيض واحد على الداكن أو الصور.
- `opsone-logo-1200.png`, `opsone-logo-reversed-1200.png`, `opsone-mark-512.png`, `opsone-mark-reversed-512.png` — نسخ نقطية للبريد والمستندات حيث لا يُقبل SVG.

اترك حول الشعار فراغًا لا يقل عن ربع ارتفاع العلامة. لا ينعكس في RTL.
