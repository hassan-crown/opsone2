# App icons

- `opsone-app-icon.svg` / `opsone-app-icon-1024.png` — أيقونة التطبيق: العلامة المعكوسة على مربع `ink-900` بزوايا مستديرة.
- `opsone-app-icon-light.svg` — النسخة الفاتحة: العلامة الأصلية على الأبيض.
- `favicon.svg`, `favicon-32.png`, `favicon-16.png` — أيقونة المتصفح. `apple-touch-icon-180.png` — اختصار الشاشة الرئيسية في iOS.

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon-32.png" sizes="32x32">
<link rel="apple-touch-icon" href="/apple-touch-icon-180.png">
```
