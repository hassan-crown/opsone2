مسار التشغيل

اختر أقرب قالب لعملك؛ هو نقطة بداية لا قيد.
قالب البداية
بعد الاختيار مساحتك تعمل بالمسار الافتراضي منذ تجهيزها؛ اختيار قالب آخر يستبدله فورًا للطلبات الجديدة. التخطي يبقي الافتراضي، فلا يتوقف فتح الطلبات أبدًا. أي تعديل لاحق يسري على الطلبات الجديدة فقط.

مكانه الدائم: الإعدادات، مسار التشغيل.
