ORD-24518. أُرسل 25 أكتوبر 10:15. بانتظار موافقتك.
أهم البنود
الأطراف
مطابخ الركن الحديث، ومنيرة الشمري.
الموضوع
تصنيع وتوريد وتركيب وحدات المطبخ والجزيرة وفق التصميم المعتمد.
المدة

الضمان

شروط إضافية
تُسلَّم الأجهزة المدمجة للفريق قبل موعد التركيب بيومين.
