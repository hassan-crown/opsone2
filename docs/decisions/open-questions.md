# سجل القرارات المفتوحة

> المصدر الوحيد للقرارات المفتوحة في OpsOne. يجمع: [`design-system-integration.md`](../design-system-integration.md) §14–15،
> [`screens-inventory.md`](../screens-inventory.md) §3–4 و§7، وفجوات وثائق التحليل (BRD، SRS، المصفوفة، الحالات).
> طريقة الإجابة في [`working-agreement.md`](../working-agreement.md) (البوابة G2). القرار المعتمد ينتقل إلى ADR إذا كان معماريًا.

**الحالات:** `open` = بانتظار مالك المنتج · `decided-default` = لم يُجب والقرار قابل للرجوع، فنمضي بالتوصية ويُعلَّم في الـ PR · `decided` = اعتمده مالك المنتج أو ADR.
**قاعدة:** البند غير القابل للرجوع (مال، أمن، عقد خارجي، تكلفة) لا يصبح `decided-default`؛ يوقف مرحلته حتى الإجابة.
