# لقطات التذاكر (P8 — الجزء د)

الالتقاط من متصفح التطبيق المدمج على بيئة الجلسة المحلية ببيانات `DemoSeeder` وثلاث تذاكر تجريبية لعميلة تجريبية
(واحدة مرتبطة بطلب بانتظار العميل، وعامة جديدة، وعامة قيد المعالجة فيها رد ظاهر وملاحظة داخلية). دخول العميل فعليًا برمز
لمرة واحدة. جوال العميل 390×844، وإدارة المنشأة 1280×800، الثيم فاتح، `ar` RTL و`en` LTR.

| الملف | الشاشة |
|---|---|
| `tickets-mobile-*` | `Tickets`: قائمة تذاكر العميل وحالاتها |
| `ticket-new-mobile-*` | تذكرة جديدة مرتبطة بطلب (أو «بلا طلب: سؤال عام») مع مرفقات |
| `ticket-page-mobile-*` | `TicketPage` للعميل: الحوار الظاهر فقط وصندوق الرد |
| `staff-inbox-desktop-*` | صندوق الموظف ضمن نطاقه |
| `staff-ticket-desktop-*` | صفحة التذكرة للموظف: ملاحظة داخلية مميزة بصريًا بلا ظهور للعميل |
