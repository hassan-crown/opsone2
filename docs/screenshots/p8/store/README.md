# لقطات المتجر والدفع (P8 — الجزء ج)

التُقطت آليًا عبر Chrome محلي (بروتوكول DevTools) على البيئة المحلية للجلسة `opsone_p8c` ببيانات `DemoSeeder` وترخيص
التطوير وبيانات متجر تجريبية (4 منتجات جاهزة بمخزون في MAIN، كوبونان، روابط سلال، وشراء معلق بفاتورة ميسر مُحاكاة
محليًا دون أي اتصال حقيقي). دخول العميل تم فعليًا برمز لمرة واحدة، ودخول الموظف بحساب المالك التجريبي.
الجوال 390×844 (بضعف الكثافة)، سطح المكتب 1440، الثيم فاتح، لغتان (`ar` RTL و`en` LTR).
الاسم: `<الشاشة>-<mobile|desktop>-<ar|en>-light.jpg`.

| الملف | الشاشة |
|---|---|
| `store-list-*` | `StoreList`: منتجات جاهزة منشورة بسعرها وتوفرها من مخزون فرع الاستلام |
| `store-product-*` | `StoreProduct`: اختيار النوع (غير المتوفر معطل) والكمية والإضافة للسلة |
| `store-cart-*` | `StoreCart`: سلة الجلسة؛ لا تحجز مخزونًا |
| `checkout-*` | `Checkout`: صفحة واحدة بأربعة أقسام (المنتجات، التحقق برمز الجوال Q-48 أ، الاستلام من الفرع، الكوبون قبل الضريبة والدفع) |
| `checkout-pending-*` | `CheckoutPending`: حالة من الخادم فقط، لا تؤكد شيئًا، مع متابعة الدفع أو الإلغاء |
| `links-*` | `LinksMobile`: إصدار رابط سلة ونسخه واستبداله وإلغاؤه (P-92/P-93) |
| `coupons-*` | `Coupons`: الحالة (مجدول/فعال/موقوف/منتهٍ) والحدود والاستخدام (P-91) |
| `coupon-new-*` | `CouponNew`: الرمز والنوع والقيمة والمدة والنطاق والحدود |
| `store-settings-*` | `StoreSettings`: فتح المتجر وفرع الاستلام ومدة الحجز وصلاحية الروابط، وحساب ميسر بوضع الاختبار فقط |
