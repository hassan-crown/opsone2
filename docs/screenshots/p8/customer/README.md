# لقطات مساحة العميل (P8 — الجزء ب)

الالتقاط من متصفح التطبيق المدمج على البيئة المحلية للجلسة ببيانات `DemoSeeder` وترخيص التطوير وبيانات تجريبية للعميل
(طلبان مخصصان: اتفاق معتمد وتصميم بانتظار الموافقة وسند وإيصال قيد المراجعة وموعد بانتظار التأكيد، وعرض سعر بانتظار
الموافقة). الدخول تم فعليًا برمز لمرة واحدة. الجوال 390×844 (يُحفظ بضعف الكثافة)، الثيم فاتح، لغتان (`ar` RTL و`en` LTR).
الاسم: `<الشاشة>-mobile-<ar|en>-light.jpg`.

| الملف | الشاشة |
|---|---|
| `login-*` | دخول العملاء: الجوال أو البريد بلا كلمة مرور |
| `verify-*` | إدخال الرمز، مع مهلة إعادة الإرسال؛ لا يكشف وجود الحساب |
| `activate-*` | `ActivateAccount` من رابط الموظف: الوجهة مقنّعة والرمز مطلوب |
| `home-*` | `CustHome`: «مطلوب منك» أولًا ثم الطلبات والتحديثات |
| `orders-*` | `CustOrders`: المفتوحة والمكتملة مع المحطة العامة الحالية |
| `order-*` | `CustOrder`: المستحق الآن ورحلة الطلب (المحطات الظاهرة للعميل فقط) |
| `documents-*` | `CustDocs`: التصاميم، العروض والعقود، سندات القبض |
| `doc-approve-design-*` | `DocApprove` لتصميم بملفه |
| `doc-approve-quote-*` | `DocApprove` لعرض سعر ببنوده وضريبته وشروطه |
| `pay-*` | `PayOrder`: جدول الدفعات وإرسال إيصال التحويل (قيد المراجعة حتى التأكيد) |
| `cancel-request-*` | `CancelRequest`: الإرسال بسبب، والقرار للجهة |
| `updates-*` | التحديثات المشتقة من السجلات |
| `settings-*` | الحساب واللغة والخروج من كل الأجهزة |
