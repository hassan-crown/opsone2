# لقطات شاشات الطلبات (P4)

الالتقاط من متصفح التطبيق المدمج على `http://localhost:8087` ببيانات `DemoSeeder` وترخيص التطوير (نمو)، مع طلبات تجريبية.
حاسوب 1280 وجوال 375، الثيم فاتح، لغتان (`ar` RTL و`en` LTR). الاسم: `<الشاشة>-<desktop|mobile>-<ar|en>-light.jpg`.

الشاشات: `orders-list` (القائمة)، `order-create` و`order-create-lines` (إنشاء طلب مخصص: العميل والبند المثبّت على إصدار)،
`order-overview` (صفحة الطلب)، `order-history` (سجل الحالات من `state_transitions`)، `order-transfer` (نقل الفرع مع صندوق الأثر)،
`order-conflict` (تغيّرت البيانات أثناء الإجراء).

المتوفر حاليًا: القائمة والإنشاء وصفحة الطلب بالعربية والإنجليزية على الحاسوب والجوال؛ وسجل الحالات ونقل الفرع وتعارض النسخة
بالعربية والإنجليزية على الحاسوب. الجوال بدقة 375×812 (يُحفظ بضعف الكثافة).
اللقطات الإنجليزية الثلاث الأخيرة التُقطت بـ Chrome بلا واجهة عبر بروتوكول DevTools على 1280×800 ثم صُغّرت إلى 800×500 كبقية اللقطات.
