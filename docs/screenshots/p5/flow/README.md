# لقطات شاشات مسار التشغيل وتقدّم الطلب (P5)

الالتقاط من متصفح التطبيق المدمج على `http://localhost:8090` ببيانات `DemoSeeder` وترخيص التطوير، مع طلبين مخصصين تجريبيين.
حاسوب 1280×800 (تُحفظ 800×500) وجوال 375×812 (تُحفظ بضعف الكثافة)، الثيم فاتح، لغتان (`ar` RTL و`en` LTR).
الاسم: `<الشاشة>-<desktop|mobile>-<ar|en>-light.jpg`.

مسار المنشأة (`/settings/flow`): `flow-published-stage` (النسخة المنشورة للقراءة فقط مع مرحلة مفتوحة، `FlowStage`)،
`flow-draft` (المسودة قابلة للتعديل، `FlowEdit`)، `flow-add-action` (`FlowAddAction`)، `flow-action-design` و`flow-action-payment`
(محررا إجراء، `FlowAction_design` و`FlowAction_pay`)، `flow-check` (`FlowCheck` بخطأ مربوط بالمرحلة والإجراء)،
`wizard-flow` (خطوة المعالج `WizardFlow`).

صفحة الطلب، تبويب «المراحل والمهام»: `order-stages` (`OrderStages` مع المانع وإصدار المسار المثبّت)،
`order-complete-stage` (`OrderCompleteStage` بمتطلب مفتوح)، `order-allow` (السماح بالمتابعة بسبب)، `order-stages-completed`
(بعد الإكمال)، `order-rework` (`OrderRework`)، `order-pause` (`OrderPause`)، `order-paused` (الطلب موقوف)،
`order-edit-upcoming` (`OrderEditUpcoming`).

الجوال: `flow-published-mobile` و`order-stages-mobile` بالعربية والإنجليزية. باقي الإجراءات (المحررات العشرة) تشترك في الإطار نفسه؛ التُقط منها محرران.
