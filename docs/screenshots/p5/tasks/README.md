# لقطات شاشات المهام (P5 — مهام المنفذ)

الالتقاط من متصفح التطبيق المدمج على `http://localhost:8089` ببيانات `DemoSeeder` وترخيص التطوير، مع طلبات ومهام تجريبية
(مهام مسندة للمنفذ، ومهام في صندوق قسم الإنتاج للمشرف). الجوال 375×812 (يُحفظ بضعف الكثافة) والحاسوب 1280×800 (يُحفظ 800×500)،
الثيم فاتح، لغتان (`ar` RTL و`en` LTR). الاسم: `<الشاشة>-<mobile|desktop>-<ar|en>-light.jpg`.

| الملف | الشاشة |
|---|---|
| `exec-home-mobile-*` | `ExecHomeMobile` / `TaskEmpty`: رئيسية المنفذ (اليوم والقادمة) |
| `task-list-mobile-*` | `TaskList` على الجوال (بطاقات) |
| `task-mobile-*` | `TaskMobile`: صفحة المهمة بدور المنفذ |
| `measure-mobile-*` | شاشة إدخال القياسات للمنفذ (Q-32) |
| `home-cards-desktop-*` | بطاقتا «مهامي» و«صندوق القسم» في الرئيسية بعدّادات حقيقية |
| `task-list-inbox-desktop-*` | `TaskList` عرض صندوق القسم (تولي المهمة) |
| `task-assign-desktop-*` | `TaskAssign`: المؤهلون بعدد أعمالهم، والتوجيه إلى صندوق قسم |
| `task-desktop-*` | `TaskPage` على الحاسوب (غير مسندة، إجراءات المشرف) |

`TaskWaiting` نافذة حوار فوق صفحة المهمة (لم تُلتقط منفصلة). الصفحة نفسها متجاوبة، فلا لقطات منفصلة للداكن.
