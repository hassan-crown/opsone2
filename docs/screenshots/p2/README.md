# لقطات المرحلة P2 (شاشات المنظمة)

الالتقاط بمتصفح Chromium آلي (Playwright) من `http://localhost:8084` على بيانات `DemoSeeder` المحلية وترخيص التطوير (نمو، 3 فروع). عرض 1280 للحاسوب و375 للجوال، الثيم فاتح، لغتان (`ar` RTL و`en` LTR). الاسم: `<الشاشة>-<desktop|mobile>-<ar|en>-light.jpg`.
