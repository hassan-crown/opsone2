# مجموعة تقييم الذكاء الاصطناعي (AI eval)

مرجعها: [خطة الذكاء الاصطناعي §3.6](../../../docs/analysis/ai-v1-plan.md) و[ADR-0050](../../../docs/decisions/0050-ai-assistant.md).

- **أمثلة مصطنعة فقط** (Q-96): لا بيانات منشآت حقيقية إلا بموافقة مكتوبة وبعد الإخفاء، وتُحفظ هنا لا لدى المزود.
- **لا تُشغَّل في CI.** الاختبارات الآلية في `tests/Feature/Ai` تستعمل المشغّل `fake`.
- كل ملف `fixtures/<axis>.jsonl` محور، وكل سطر مثال JSON:

```json
{"id": "najdi-status", "task": "intent.classify", "system": "...", "instruction": "...",
 "facts": {}, "untrusted": ["نص العميل"], "known": {"ADDRESS": ["..."]}, "schema": {...},
 "expect": {"outcome": "ok", "equals": {"intent": "order_status"}, "not_contains": ["50%"]}}
```

## التشغيل

```bash
./manage.sh artisan ai:eval            # كل المحاور
./manage.sh artisan ai:eval intent --limit=20
```

- بالمشغّل الافتراضي `log` لا يُرسل شيء: يتحقق الأمر من صحة كل مثال فقط.
- بالمشغّل `anthropic` (بعد Q-94 فقط، وبمفتاح مساحة عمل التقييم لا مفتاح منشأة) يرفض الأمر دون `--confirm-cost`.
- استدعاءات التقييم لا تخصم رصيد المنشأة، لكنها تمر بالإخفاء والمدقق وتُسجَّل في `ai_usage` كأي استدعاء.

## الحد الأدنى قبل تفعيل كل محور (الخطة §3.6)

| الملف             | المحور                  | الحد الأدنى              | الموجود الآن  |
| ----------------- | ----------------------- | ----------------------- | ------------ |
| `flow.jsonl`      | 1 بناء المسار           | 30 وصفاً عبر 9 قطاعات    | يُضاف مع AI-1 |
| `reply.jsonl`     | 2 الرد المقترح          | 100 محادثة              | 1 (هيكل)     |
| `order.jsonl`     | 3 من المحادثة إلى الطلب | 60 محادثة بصور          | يُضاف مع AI-5 |
| `intent.jsonl`    | 4 تصنيف النية           | 200 رسالة               | 4 (هيكل)     |
| `injection.jsonl` | الحقن (كل المحاور)      | 80 محاولة               | 2 (هيكل)     |
| `data.jsonl`      | 6 اسأل بياناتك          | 50 سؤالاً على بيانات seed | يُضاف مع AI-8 |
| `help.jsonl`      | 7 المساعدة              | 60 سؤالاً لكل الأدوار      | 2 (هيكل)     |
| `measure.jsonl`   | 8 المقاسات              | 100 ورقة                | يُضاف مع AI-9 |

الأمثلة باللهجات (نجد، والحجاز، والخليج)، ومع أخطاء إملائية، وخلط عربي-إنجليزي، وأرقام هندية (٣٢٠ سم).
**بوابة التغيير:** أي تغيير في نموذج أو تعليمات يمر بالتقييم ويُقارن بالخط الأساسي قبل الدمج.
